# オモチとG検定！

博士と学習中の猫「オモチ」の掛け合いで1つずつ概念を学び、最後に「誤っているものを1つ選ぶ」4択問題を解く、Codex用の学習プロジェクトです。全55単元・444テーマの学習順、到達目標、確認方法、495項目の公式キーワード対応を同梱しています。444は公式問題数ではなく授業用のテーマ数です。

## 始め方

Gitと、ローカルフォルダのファイルを読み書きできるCodex環境を使います。専用のAPIキー、Python、追加プラグインは不要です。公式資料の確認にはインターネット接続を使います。

1. `git clone https://github.com/n4tt0u/g-kentei-study.git` で取得します。
2. 取得したフォルダをCodexのプロジェクトとして開きます。
3. 新しいチャットで「学習を始めて」と伝えます。

「続きから」で保存された現在地から再開。「次」で次の説明と問題へ、「別の例で説明して」で補足、「休憩」で停止します。問題文とA〜Dの選択肢はチャット本文に表示します。回答は「B」のように文字で入力してください（小文字・全角も可）。

モデルや環境によって文章・難易度には差が出ます。このリポジトリは全用語の固定教材・固定問題集ではなく、公式範囲に沿って説明と練習問題を生成するためのルールと見本です。

## 記録

初回にCodexが `templates/` から `learner/` を作成します。現在地、未回答問題、回答履歴、復習候補をローカル保存するので、新しいチャットでも再開できます。オモチの発言は教材上の設定で、利用者の回答としては記録しません。

`learner/` は `.gitignore` でGit管理から除外しています。これは暗号化やバックアップではありません。必要なら自分で別の非公開の場所へバックアップしてください。

## 更新方法

授業が一区切りついたところで、同じフォルダのターミナルから実行します。

```sh
git pull --ff-only
```

その後、新しいチャットで「続きから」と伝えてください。配布側は `learner/` にファイルを配布しないため、各自の記録を維持したままルールを更新できます。カリキュラム更新時は、下記の履歴照合も実行します。共有ファイルに独自の編集がある場合は更新が止まることがあります。強制リセットせず、変更を確認してください。個人的な好みは `learner/preferences.md` に保存する運用を基本にします。

## 既に学習を始めている人：カリキュラム更新

新しいチャットへ移る前に、今まで学習していたチャットで次を伝えてください。

> このリポジトリを最新mainに更新し、learning/history-migration.mdに従って、私自身の学習履歴を全範囲444テーマへ対応付けてください。履歴をバックアップして進捗・回答・未回答問題・設定を保持し、不明は不明のままにしてください。結果と不足・次の候補を保存して報告し、まだ授業は始めないでください。

詳しい手順とそのまま渡せる指示文は [履歴の対応付け](learning/history-migration.md) にあります。更新だけで本人の履歴が公開元へ送られることはありません。クラウドで別タスクの履歴が見えない場合、GitHub更新だけでは復元できません。現在のチャットや本人のバックアップが必要です。

## ファイル

- `AGENTS.md`：Codexが読む入口と必須条件
- `learning/method.md`：対話・作問・解説・復習のルール
- `learning/curriculum.md`：全55単元・444テーマの本文、到達目標、確認方法
- `learning/curriculum.json`：テーマIDとキーワード・公式例題の対応
- `learning/keyword-coverage.csv`：公式キーワード495項目の対応表
- `learning/history-migration.md`：既存学習者の履歴を対応付ける手順
- `learning/recording.md`：保存・再開の手順
- `learning/examples.md`：授業と解説の架空の見本
- `templates/`：個人記録の初期ひな型
- `MAINTAINING.md`：配布版への反映・確認手順
- `CHANGELOG.md`：版ごとの変更

公式シラバス・公式例題は [JDLAの公式案内](https://www.jdla.org/certificate/general/) と [公式例題](https://www.jdla.org/certificate/general/issues/) を参照します。JDLAの公式教材ではありません。第三者資料や公式問題の全文は同梱していません。

## スマホからクラウド版Codexで試す場合

この版はローカル利用を基本に作っています。スマホ・クラウドでの授業動作は未検証です。次の流れで試せますが、アカウント・アプリでCodex Cloudを利用できることが前提です。

1. WebまたはPC側で、各自がこのリポジトリを使えるCodexのクラウド環境を準備します。公開リポジトリでも、環境へのアクセス設定は別に必要です。
2. スマホのChatGPTでCodexのCloudと対象環境を選びます。表示されない場合はアプリ・アカウント側の提供状況を確認します。
3. 最初のメッセージに「AGENTS.mdを読み、学習を始めて」と入力します。初回に公式シラバスを取得・確認できるよう、クラウド環境のネットワークを設定してください。
4. 最初は同じタスクを開いて学習を続けます。問題はモーダルを使わずチャット本文に表示し、A〜Dをチャットで回答します。

新しいクラウドタスクは別の作業ファイルを持ち、前タスクの `learner/` は自動では引き継がれません。この版にはタスク間の個人記録の永続保存・復元機能はありません。学習記録を公開リポジトリへpushしないでください。試行では授業・回答・採点までを確認し、継続運用の保存方法は別途検討します。

参考: [クラウド環境](https://learn.chatgpt.com/docs/environments/cloud-environments)、[モバイル利用](https://learn.chatgpt.com/docs/mobile)。
