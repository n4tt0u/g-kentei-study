# 博士とオモチのG検定学習

博士と学習中の猫「オモチ」の掛け合いで1つずつ概念を学び、最後に「誤っているものを1つ選ぶ」4択問題を解く、Codex用の学習プロジェクトです。

## 始め方

Gitと、ローカルフォルダのファイルを読み書きできるCodex環境を使います。専用のAPIキー、Python、追加プラグインは不要です。公式資料の確認にはインターネット接続を使います。

1. 共有されたGitHubリポジトリを `git clone <共有URL>` で取得します（この `<共有URL>` は実際のURLへ置き換えます）。
2. 取得したフォルダをCodexのプロジェクトとして開きます。
3. 新しいチャットで「学習を始めて」と伝えます。

「続きから」で保存された現在地から再開。「次」で次の説明と問題へ、「別の例で説明して」で補足、「休憩」で停止します。回答はA〜Dの文字でも受け付けます。

モデルや環境によって文章・難易度・選択UIには差が出ます。このリポジトリは全用語の固定教材・固定問題集ではなく、公式範囲に沿って説明と練習問題を生成するためのルールと見本です。

## 記録

初回にCodexが `templates/` から `learner/` を作成します。現在地、未回答問題、回答履歴、復習候補をローカル保存するので、新しいチャットでも再開できます。オモチの発言は教材上の設定で、利用者の回答としては記録しません。

`learner/` は `.gitignore` でGit管理から除外しています。これは暗号化やバックアップではありません。必要なら自分で別の非公開の場所へバックアップしてください。

## 更新方法

授業が一区切りついたところで、同じフォルダのターミナルから実行します。

```sh
git pull --ff-only
```

その後、新しいチャットで「続きから」と伝えてください。配布側は `learner/` にファイルを配布しないため、各自の記録を維持したままルールを更新できます。共有ファイルに独自の編集がある場合は更新が止まることがあります。強制リセットせず、変更を確認してください。個人的な好みは `learner/preferences.md` に保存する運用を基本にします。

## ファイル

- `AGENTS.md`：Codexが読む入口と必須条件
- `learning/method.md`：対話・作問・解説・復習のルール
- `learning/curriculum.md`：公式範囲に対応する学習順
- `learning/recording.md`：保存・再開の手順
- `learning/examples.md`：授業と解説の架空の見本
- `templates/`：個人記録の初期ひな型
- `MAINTAINING.md`：配布版への反映・確認手順
- `CHANGELOG.md`：版ごとの変更

公式シラバス・公式例題は [JDLAの公式案内](https://www.jdla.org/certificate/general/) と [公式例題](https://www.jdla.org/certificate/general/issues/) を参照します。JDLAの公式教材ではありません。第三者資料や公式問題の全文は同梱していません。

現在はローカル配布準備版です。GitHubの共有URLは公開後に案内します。
