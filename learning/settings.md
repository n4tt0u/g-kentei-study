# 個人設定と配布更新

共有教材は既定値を持つ。利用者が自分の環境で採用した設定は、その利用者の設定として保持する。配布元の学習ペースや出題形式を本人の希望とみなさない。

## 優先順位

本人の現在の明示指示 → `learner/preferences.md` 等に保存した採用済み設定 → 今の学習チャットで本人が採用した設定 → 共有版の既定値。

設定は本人の発言・採用を確認したものに限る。preferences.mdに書かれていても、ひな型をコピーしただけの既定値は採用済み個人設定とは扱わない。AIが提案しただけの形式、教材内の例文、過去の未採用案を採用済みとみなさない。矛盾が解消できない項目だけ確認し、他の確定した設定は維持する。

## 今回の更新（0.2.1）

共有版から取り込む変更は、次の2点。

1. 掛け合いの説明を要点3つ・代表例1つを基本にする。3〜5往復は目安で、理解や公式目標の確認に必要なら補足する。意味・用途・似た用語との差・代表的注意点を中心にする。
2. 図を示す場合は `mermaid` のコードフェンスを使う。図を全テーマで必須にはしない。

今回の更新を取り込むときも、出題形式など他の個人設定を既定値に戻さない。本人がその後に説明方法や図について別の希望を明示した場合は、その指示を優先する。

## 保持する項目

- 誤りを選ぶ／正しいものを選ぶ等の出題方針、選択式・記述式等の回答形式、選択肢数とラベル（A〜D、1〜4等）。
- 1回のテーマ数・問題数、問題を出すタイミング、作者ラベルの有無、回答の入力方法、解説の詳しさ。
- 採点後に止める／条件付きで続ける等の進行、日別目標・学習日境界、復習・休憩の希望。
- 現在地、過去の回答と正誤、未回答問題の本文・選択肢・正解キー、問題の連番と復習候補。
- その他、本人が採用した個人設定。任意のスキルの新規インストールや他者のスキル設定を、この更新で追加しない。

共有の見本は既定値の例であり、本人の設定を上書きする根拠ではない。記録に残る採用済み設定が見つかったら、根拠を添えて `learner/preferences.md` に統合する。既存内容は消さず、設定ファイルをひな型で置き換えない。
