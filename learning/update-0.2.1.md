# 説明と図だけを更新する（0.2.1）

今まで学習していたチャットで行う。全カリキュラムの再照合や学習のやり直しは、この更新だけでは不要。

1. 今のチャットと `learner/`、手元で変更した共有ファイルを確認し、採用済みの出題・進行設定を把握する。曖昧な項目は推測で既定値へ戻さない。
2. 既存の個人記録と必要な設定を `learner/backups/<実行日時>/` へ退避する。backups自体は再帰コピーしない。共有ファイルを個別に修正していた場合はその差分も保持し、学習上の希望を根拠とともに `learner/preferences.md` へ統合する。変更したという理由だけで本人の採用と断定しない。
3. remoteと作業コピーを確認し、未保存の共有変更がなければ最新mainへ `git pull --ff-only`。衝突・分岐があれば強制リセットしない。最新教材を別コピーへ取得して差分を確認し、個人の変更を統合する。取得・確認できない場合は更新完了と言わない。
4. `learning/settings.md` に従い「要点3つ＋例1つ中心の掛け合い」と「図はMermaid」のみを反映する。本人が調整した他の設定・回答履歴・未回答問題を保持する。`templates/` を既存 `learner/` にコピーし直さない。
5. 保存前に設定と未回答問題のID・内容・正解キー・連番・履歴が変更されていないことを照合する。内容が保たれた場合だけ `state.method_version` を0.2.1へ更新し、必要なら変更点を個人領域へ記録する。既に同版なら差分確認だけにし、同じ記録を重複追加しない。
6. 反映した2点と保持した設定を短く報告して止める。更新指示だけで授業や採点を始めない。実際の相手環境で確認できた範囲と、確認できない範囲を分けて伝える。
